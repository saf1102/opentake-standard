# Windows runtime distribution notices

The full offline installer is a local Windows build from the supplied OpenTake snapshot, not an official OpenTake or OpenScreen release. OpenTake modifications remain AGPL-3.0-only; see LICENSE, NOTICE and TRADEMARK.md. The source archive accompanying this installer contains the complete OpenTake changes and pinned native capture-helper source.

The separately runnable programs below are bundled as application-local tools. Their original copyright, license and third-party notices are retained under `resources/runtimes` and listed in `manifest.json`. The source-only archive contains no account files and no runtime binaries.

- **OpenScreen 2.1.2**: MIT, Siddharth Vaddem and OpenScreen contributors. `openscreen/resources/LICENSE`, `THIRD-PARTY-NOTICES.md` and `THIRD-PARTY-LICENSES.txt` cover the desktop app, compositor, FFmpeg DLLs, models, fonts and other upstream components. Exact upstream source: https://github.com/getopenscreen/openscreen/tree/d8889c626f859e0be8f4f87fdffc7362629550bc . The bundled WGC helper has the MIT-licensed recording clock fix; the native compositor has a software-decoding fallback when D3D11VA initialization fails. Both original components are preserved. The compositor patch and exact upstream/SDK hashes are in vendor/openscreen-compositor and the runtime sources folder. The official app.asar hash remains unchanged.
- **FFmpeg / ffprobe n8.1.3-24-g92611900bb (20261027)**: LGPL-3.0-or-later shared build from BtbN, without `--enable-gpl` or `--enable-nonfree`, no libx264/libx265. Original license texts and build configuration are retained; developer headers, examples, player and manuals are excluded. Exact FFmpeg source: https://github.com/FFmpeg/FFmpeg/tree/92611900bb ; build scripts and dependency source recipes: https://github.com/BtbN/FFmpeg-Builds/tree/autobuild-2026-10-27-18-38 . The corresponding upstream source archives/build recipes and configure output are also included in the runtime sources folder. Dynamic DLLs remain replaceable; this distribution imposes no restriction on LGPL-permitted modification or reverse engineering for debugging modifications. See https://ffmpeg.org/legal.html .
- **Python 3.14.10**: PSF-2.0 and included third-party notices in `python/LICENSE.txt`. Official release: https://www.python.org/downloads/release/python-31410/ . The local embed path file adds only the app's audio module path and local site-packages; sitecustomize restores script-directory imports and disables bytecode writes. No system Python is changed.
- **NumPy 2.5.4, SciPy 1.18.1, Numba 0.68.1, llvmlite 0.50.0, Pillow 13.0.0**: original PyPI Windows wheels. Complete license texts, including bundled OpenBLAS/LLVM and other third-party libraries, remain in each package's `.dist-info` directory and package subdirectories under `python/Lib/site-packages`. Exact download hashes and URLs are in provenance.json.
- **Chromium Headless Shell 153.0.8010.12**: BSD and third-party licenses in `browsers/chromium_headless_shell-1243/chrome-headless-shell-win64/LICENSE.headless_shell`; original ABOUT is retained. Source: https://chromium.googlesource.com/chromium/src/+/153.0.8010.12 . The separate branded Chrome desktop browser is not included. Playwright runtime license remains in app licenses/npm.
- **Codex CLI 0.165.0**: Apache-2.0, OpenAI. Official Windows native package includes executable, resources and sandbox helpers, with LICENSE and NOTICE in `codex`. Source: https://github.com/openai/codex/tree/rust-v0.165.0 . No credentials, personal configuration or account data is bundled. Login and OS sandbox authorization remain the user's actions.
- **Electron 41.10.7**: MIT and bundled Chromium/Node.js third-party components; see `LICENSE.electron.txt`, `LICENSES.chromium.html` and app licenses/npm.
- **Node.js 24.21.0 export worker**: official Windows x64 archive, with upstream MIT/third-party notices in `export-node/LICENSE`. Source: https://github.com/nodejs/node/tree/v24.21.0 .
- **Jianying draft generation**: pinned PyPI wheels for pyJianYingDraft 0.3.0, pymediainfo 7.0.1 (including its MediaInfo DLL), imageio 2.38.1, uiautomation 2.0.29 and comtypes 1.4.17. No Jianying application binaries, accounts or user drafts are included. Jianying is separately installed by the user to open/edit the generated drafts. No GUI automation is used to import drafts.
